## 1.6.14 Image Thumbnails & Fixes 🖼️

- Image attachments in chat now show as thumbnails, and can be clicked to enlarge or removed. (#636)
- The / menu of the CodeBuddy runtime now supports picking user-level and project-level skills. (#634)
- Improved the hint for queuing a message while a run is in progress, explaining that the message is handed to the Agent once the current step finishes. (#637)
- Fixed the tool counts disagreeing between the Agent editor, the Agents cards, and the Agent selector; the Agent selector now shows the number of enabled skills.
- Fixed all edits made after renaming a whiteboard not being saved. (#633)
