# 模块

模块是独立安装、独立更新的功能包。它们不随插件本体一起打包，你需要时才装。

管理位置：**设置 → YOLO → 模块**。

## 安装和管理

模块来自官方维护的模块目录，不是任意第三方仓库。设置页里分「已启用」「已停用」「可用」三组。

每个模块卡片上有图标、名称、版本号、描述，以及随状态变化的操作按钮：安装 / 启用 / 更新 / 更新并启用 / 停用 / 卸载。

有更新时版本号会显示成 `v1.2 → v1.3` 的高亮形式。

**装不了的情况**会直接写明原因：平台不支持、需要先升级 YOLO 本体、或者数据结构不兼容。这类情况下不会给你安装按钮。

下载或激活失败会显示具体是哪一步出的问题（超时 / 下载失败 / 完整性校验失败 / 激活失败），可以重试。

模块装好后，如果它有自己的设置项，会作为独立条目出现在模块页左侧导航里。

> 装了模块之后你可能会发现对话里多出新工具、或者模式下拉里多了新选项——这是正常的，模块可以向对话贡献自己的工具和聊天模式。

# 学习模块

把一个主题和一堆资料，变成结构化的学习内容：大纲、知识点、闪卡、习题、知识图谱，再配合间隔重复帮你真的记住。

> 学习模块目前处于**公开测试阶段**。首次进入会有一个说明需要你确认后才能继续。

## 打开

左侧功能区的毕业帽图标，或命令面板「打开学习模式」。

## 创建一个学习项目

在学习中心点「新建项目」，需要填：

- **学习主题** —— 比如"React"、"刑法总则"
- **学习模式** —— 目前「标准模式」可用（生成知识体系 + 卡片 + 习题），「项目制模式」标着即将推出
- **当前水平** —— 零基础 / 了解概念 / 有一定经验 / 进阶提升
- **学习目标与补充要求** —— 自由文本。可以写时间安排、应用场景，也可以写明不想学什么
- **参考资料**（可选）—— 拖拽上传 PDF、Word、Markdown，单文件不超过 20MB。传了资料 AI 会据此定制大纲

### 生成流程是分步的

不是一次生成完，中间有你确认的环节：

1. 点「创建并生成大纲」，AI 先规划学习路径和章节结构
2. **大纲出来后你可以改** —— 增删章节、拖拽排序、修改章节标题和覆盖范围说明
3. 确认无误后点「确认大纲并生成知识点」，按章节逐个生成
4. 之后生成卡片

这个"先出大纲让你改"的设计是有意义的：大纲错了后面全错，改大纲比改一百张卡片便宜得多。

**生成可以在后台跑**，你切到别的界面它继续，完成后会通知你。

**中断了可以续传** —— 重新打开项目会看到"已生成 N/M 章"的提示，点「从当前章继续」接着跑。注意这个能力是后来加的，在它上线之前创建的老项目无法自动续传。

## 项目里有什么

打开一个项目后有四个标签：

| 标签 | 内容 |
|------|------|
| **大纲** | 章节和知识点的树状结构。可以搜索、单独重新生成某个知识点、查看每个知识点的卡片数和掌握度、跳转到对应笔记 |
| **知识地图** | 知识点之间关系的图谱 |
| **卡片** | 闪卡。点击或空格翻面，用「忘了 / 重来 / 模糊 / 会了 / 简单」评分。可以按章节筛选，也可以手动增删改和暂停某张卡 |
| **习题** | 问答式练习。你写答案，AI 给出要点对照、遗漏或错误、完整讲解和参考答案 |

## 间隔重复复习

卡片和习题都走 FSRS 算法调度。

学习中心首页有「开始今日复习」，直接进入今天到期的全部卡片——**会跨项目合并**，不用一个个项目点进去。项目内的卡片标签页也可以只复习本项目的。

复习时你的评分直接决定下次出现的时间，界面会显示下次间隔（多少分钟 / 小时 / 天）。

掌握度分三档：未开始 / 学习中 / 已掌握，在大纲和卡片列表里都能看到百分比。

首页还会汇总今日待复习数量、优先复习推荐、30 天预计记忆保持率、各项目进度。

## 从 Anki 导入

学习中心的「从 Anki 导入」，选一个 `.apkg` 文件（**最大 200MB**）。

流程是先解析预览：显示章节数、卡片数、有多少卡片带着有效的复习历史、已暂停数、媒体文件数，以及警告和跳过项。确认无误后填项目名称，再点导入。

**复习历史会一起导进来**，不是从零开始。

> **目前只有导入，没有导出。** 不能把学习模块的卡片导回 Anki。

# 白板模块

`.yoloboard` 是 YOLO 自己的无限画布格式。

## 新建和导入

- **新建**：命令面板「新建白板」，或文件菜单里的新建入口
- **从 Canvas 导入**：右键某个 `.canvas` 文件选「导入为 YOLO 白板」；批量的话用命令面板「把全部 Canvas 导入为 YOLO 白板」

批量导入会为每个 Canvas 在原位置生成一个同名白板，**原 Canvas 文件不会被改动或删除**。

## 和 Obsidian Canvas 什么关系

两种格式可以共存，互不干扰。核心差异在卡片的性质：

**YOLO 白板上的卡片是一扇指向笔记的取景窗。** 卡片记录的是"看这篇笔记的哪个位置、怎么呈现"，笔记内容本身仍然是那个普通的 Markdown 文件。白板只存窗口的位置和大小。

Obsidian Canvas 的节点更接近内嵌了内容的快照。

实践上的区别是：改笔记，白板上的卡片跟着变；卡片在白板上的位置和笔记本身无关。

## 卡片

添加方式（右键空白处或工具栏）：

- **添加笔记** —— 从库里选一篇已有笔记
- **添加媒体文件** —— 库内的图片、音频、视频
- **添加网页** —— 填 http/https 地址，或者直接把 HTML 文件拖进来

卡片可以「转为笔记」：如果这张卡还没关联到已有笔记，会把内容落盘成一篇新笔记。

引用的文件被删或移走后卡片会显示"文件丢失"占位；不支持预览的类型显示"暂不支持预览"。

## 操作

右键菜单里有：

- **分组** —— 选中多张建组，或建空分组，可重命名
- **对齐** —— 左 / 水平居中 / 右 / 顶 / 垂直居中 / 底
- **分布** —— 水平等距、垂直等距
- **整理** —— 一键自动布局
- **视角** —— 缩放到选中项、回到原点
- **连线** —— 卡片之间拉线，四种箭头样式，可以加文字标签
- **颜色** —— 六个预设色、自定义颜色，以及「无颜色」清除已设的颜色

## AI 能对白板做什么

两条路径：

**对话里的白板工具** —— 模块给对话贡献了两个工具：新建白板、编辑已打开的白板（增删移动卡片、建连线、分组）。

这些工具是**按需披露**的，你没建过白板就不会看到它们占用上下文。

编辑工具**只操作卡片和连接关系，不直接改卡片里的文字**。读白板走通用的文件读取，拿到的是一份摘要而不是几百 KB 的原始数据。

另外，YOLO 本体会**拒绝**用普通的文本编辑工具去改 `.yoloboard` 文件——防止把结构化数据当纯文本改坏。

**卡片上的内联 AI 按钮** —— 针对单张卡片的四个快捷动作：**展开 / 灵感 / 质疑 / 总结**。点击后 AI 会读这张卡和它相邻的卡片作为上下文，生成内容写回卡片。过程中可以随时停止。
