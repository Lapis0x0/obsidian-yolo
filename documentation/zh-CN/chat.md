# 对话

对话是 YOLO 的主界面。你在这里提问、让它读写笔记、执行多步骤任务。这一篇覆盖对话界面能做的全部事情。

如果你还没配好模型，请先看[快速开始](./getting-started.md)。

## 打开对话

YOLO 只有一个对话视图，但可以打开在四个位置：**侧边栏**、**新标签页**、**右侧分屏**、**独立窗口**。四个位置功能完全相同，区别只是占用屏幕的方式——侧边栏适合边写边问，独立窗口适合让 Agent 跑长任务时你继续在主窗口工作。

打开方式有三种：

- **左侧功能区图标**：点击 YOLO 图标按默认位置打开。**右键点击图标**可以临时选一次打开位置，不影响默认设置。
- **命令面板**：搜索「打开聊天」「在新标签页打开新对话」「在右侧分屏打开新对话」「在新窗口打开新对话」。
- **对话界面内的菜单**：已经打开一个对话后，可以从菜单里把它挪到别的位置。

> **YOLO 不预置任何快捷键。** 上面这些命令在全新安装时都处于未绑定状态。如果你想用快捷键唤起对话，去 Obsidian 的「设置 → 快捷键」搜索命令名自己绑定。下文提到的所有命令都是同样情况。

## 把笔记交给它：引用

对话默认不知道你在看哪篇笔记。要让它读到内容，需要显式引用。

### @ 菜单

在输入框里打 `@`，弹出引用菜单，五个分类：

| 分类 | 作用 |
|------|------|
| **文件** | 引用某篇笔记。菜单顶部通常直接带出「当前文件」，这是最常用的一项 |
| **文件夹** | 引用整个文件夹 |
| **模式** | 直接切换 Ask / Agent / Max |
| **助手** | 切换当前使用的 Agent |
| **模型** | 切换本轮使用的模型 |

打完 `@` 继续输入会在全部分类里模糊搜索，不必先选分类。

把模式、Agent、模型也放进 `@` 菜单，是为了让你在打字的过程中顺手切换，而不用把手移到别处的下拉框。

### 网页、图片和文件

这三类**不走 `@` 菜单**，各有各的入口：

- **网页**：直接把网址粘贴进输入框，它会自动变成一个网页引用。不需要额外操作。
- **图片**：点输入框的「+」按钮选择，或者直接粘贴剪贴板里的图片，或者把图片文件拖进输入区。
  前提是**当前模型支持图片输入**。如果模型没开启图片能力，上传时会提示你先去模型设置里打开「图片」模态。
- **文件附件**：同样是「+」按钮，支持 PDF、Word / PPT / Excel，以及 txt、md、csv、json、yaml、xml、log 这类纯文本格式。
  PDF 有特殊处理：对于原生支持读 PDF 的模型（Anthropic、Gemini），YOLO 会把原始文件递给模型；同时也会抽取文本作为兜底，保证换成别的模型时依然能读。

此外还有两个零散但好用的入口：在 PDF 上可以用「截取 PDF 区域到聊天」框选一块区域当图片发过去；在文件列表里对笔记或文件夹**右键**，有「添加文件到聊天」「添加文件夹到聊天」。

## 三种模式

模式决定了 YOLO **被允许做什么**。这是整个插件最重要的一个概念，选错模式会让你觉得"它怎么什么都干不了"或者"它怎么敢动我的文件"。

模式在输入框旁边的下拉框切换，也可以用 `@` → 模式。

### Ask —— 适合提问、润色与改写

只读为主。它能读笔记、检索知识库、联网搜索、在库内查找文件，但**不能编辑笔记正文**。

有一个反直觉的地方值得单独说明：Ask 模式下 YOLO 仍然可以执行 `mkdir`、`mv`、`rm` 这类**文件整理操作**（新建目录、移动、删除文件）。也就是说 Ask 不等于"绝对只读"——它不改你笔记里的字，但可以动文件本身。这类危险操作**每次都要你单独批准**，而且不允许设成"始终允许"。

### Agent —— 启用工具链，处理多步骤任务

在 Ask 的基础上增加了四样能力：

- **编辑笔记正文**（局部修改或整篇重写）
- **任务清单**：面对多步骤任务时自己列计划并逐条推进
- **分析沙箱**：在隔离环境里跑 JavaScript 做计算和批量统计
- **终端命令**：真实的本机终端（桌面端，默认需要审批）

日常让 AI 帮你整理笔记、批量改格式、根据资料写新笔记，用的就是这一档。

### Max —— 直接操作本地文件与终端（仅桌面端）

Max 突破了 Vault 的边界：它能读写**本机任意路径的文件**，不限于你的 Vault，也不限于 Markdown。终端能力也更完整，是唯一允许把终端设为"始终允许"的模式。

适合"把桌面上那堆 PDF 整理进 Vault"这类跨越 Obsidian 边界的活。**代价是它能碰到的东西远超你的笔记库**，请确认你理解这一点再用。

> 如果你在用外部 CLI Agent（Claude Code 等），还会看到一个 **Plan** 模式：先探索和出方案，你确认后才动手。详见 [CLI Agent](./cli-agent.md)。
> 安装了模块之后，模块也可能注册自己的模式，比如白板模块的专属模式。

### 「YOLO」自动放行

Agent 和 Max 底下各有一个子开关，开启后**工具调用不再逐条向你确认**。它不是第四种模式，而是叠加在这两种模式上的一个档位。

首次开启会弹风险提示，需要勾选"我已了解风险"：

- 工具调用不再逐条确认（危险命令前缀黑名单仍然拦截）
- 可能消耗较多 Token
- 请提前备份

Max + 自动放行是权限最大的组合：本机任意路径 + 写入类终端命令全部免审批。建议只在你完全清楚任务边界时使用。

## 切换模型和助手

**模型**在输入框上方的下拉框随时切换，只影响之后的消息，不会改变已经生成的历史。

**助手**是"系统提示词 + 工具偏好 + 技能"打包成的角色配置，和模型、模式相互独立。比如你可以有一个"学术写作"助手固定用某套提示词，再配任意模型和任意模式。详见[助手与子 Agent](./assistants.md)。

## 发送消息

默认 **Enter 发送、Shift+Enter 换行**。

如果你经常写多行消息，可以在设置里打开「回车换行」，行为会反过来：**Enter 换行、Cmd/Ctrl+Enter 发送**。

移动端始终是 Enter 换行，不会误发。

**Agent 正在跑的时候你仍然可以继续输入并发送**，消息会排队，等当前回合结束后继续。但有两种情况会被拦下：有工具正等你审批时，需要先批准或拒绝；模型正在向你提问时，需要先回答。中止对话时，排在队列里还没发出的消息会退回输入框，不会丢。

## 对话进行中

### 工具审批

没开自动放行时，模型每次调用工具都会在对话里出现一张工具调用卡片，上面有这些选择：

- **允许** —— 放行这一次
- **拒绝** —— 不执行，模型会收到拒绝结果并继续
- **始终允许此工具** —— 以后这个工具不再问
- **本对话内允许** —— 只在当前这轮对话里不再问
- **停止执行** —— 中止整个回合

删除、移动这类危险操作会额外弹出确认，并列出具体要删或要移的路径。派遣子 Agent 有独立的一组审批按钮（同意 / 拒绝 / 全部同意 / 全部拒绝 / 查看参数）。

模型也可能反过来问你问题——界面上标题是「模型向你发起提问」，一次最多三道，可能是单选、多选或填空。回答用 Cmd/Ctrl+Enter 提交，也可以取消本轮提问。

### 修改笔记后怎么落地

模型改笔记不是直接覆盖。它会先给出一段 diff，你点**应用**才会写进文件（应用过程中还可以终止）。

还有一个更细的「修改回顾」界面，可以逐处决定：接受这处 / 拒绝这处 / 保留 / 回退 / 合并两者，并用「上一处更改」「下一处更改」在多个改动间跳转，也可以一次性接受全部或拒绝全部。

每一轮回复下面会有一条**编辑摘要**，显示这轮改了几个文件、哪些是新建或删除，可以整体撤销，也可以只撤销其中某个文件。

> **撤销依赖本机快照，快照不随笔记一起同步。** 也就是说在另一台设备上撤销不了这里的改动；如果文件在这期间被改过、或者快照已经丢失，撤销会失败并给出提示。真正重要的改动请依赖 Git 或 Obsidian 自己的文件恢复。

### 停止、重来、改问题、开分支

- **停止生成**：输入框那里的按钮。另外 **Esc 是全局生效的**——按下会取消所有正在进行的 AI 续写和改写任务。
- **重新生成**：每条回复下方。
- **编辑已发送的消息**：点击你自己发过的消息就能改，改完重新提交，后面的对话会基于新内容重跑。
- **从此处分支**：在某条回复上创建一个新的分支会话，保留到这里为止的上下文，然后走另一个方向。想对比两种思路时很有用，原对话不受影响。

## 管理对话

### 历史记录

顶部的时钟图标打开历史列表，也可以用命令「打开聊天历史」（只在当前就停留在对话视图时可用）。

列表里可以搜索、置顶、重命名、归档、删除（点两下确认），还可以按分类过滤——「我的对话」和「任务会话」分开，任务会话还能按来源筛，包括由外部 Agent 发起的那些。

### 导出

顶部的下载图标，或命令「导出当前对话到库」，把整段对话存成 Vault 里的一篇 Markdown。只有已经保存过的会话才能导出。

### 看上下文用了多少

输入框附近有上下文占用显示，点开是分项明细：系统提示、工具、规则、技能、记忆、会话、思考过程各占多少 token，以及上一轮的缓存命中率。

两点需要知道：这是**本地估算**，和服务端实际计费会有偏差；如果你给模型配置了上下文窗口上限，这里才能显示百分比，否则会提示你去模型设置里补上。

<!-- SCREENSHOT: 上下文占用弹层展开后的分桶明细 -->

### 压缩上下文

对话太长时，可以在输入框打 `/` 选择**压缩上下文**：把较早的历史压成摘要，在新的上下文窗口里接着当前任务往下做。上下文实在放不下时 YOLO 也会自动压缩。

压缩后对话里会出现一条分隔线，标明以上内容已被压成摘要、以下回复基于摘要继续，并显示压缩后的预计 token 数。

压缩需要当前没有正在生成的回复、也没有待审批的工具，否则会提示你先处理完。
