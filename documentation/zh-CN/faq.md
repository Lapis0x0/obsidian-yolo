# 常见问题

## 安装和启动

### 装了之后没反应 / 和别的插件冲突

**YOLO 不能和 [Smart Composer](https://github.com/glowingjade/obsidian-smart-composer) 同时启用。** YOLO 由它分支而来，两者会互相冲突。先禁用或卸载 Smart Composer。

### 快捷键怎么一个都没有

**YOLO 不预置任何默认快捷键。** 所有命令在全新安装时都是未绑定状态，需要你去 Obsidian 的「设置 → 快捷键」搜索命令名自己绑。

这是为了不和你已有的快捷键打架。

## 模型和请求

### 报 CORS 错误

按顺序试：

1. 在提供商设置里打开「**无 Stainless 请求头**」——这能解决 `x-stainless-os` 之类请求头引起的报错
2. 还不行就打开「**使用 Obsidian requestUrl**」绕过 CORS。**代价是流式响应会被整体缓冲后一次性返回**，也就是没有打字机效果了
3. 桌面端也可以把「网络请求方式」改成「桌面直连」

### 回复不再是一个字一个字出现了

大概率是你打开了「使用 Obsidian requestUrl」。它会缓冲整个响应，这是绕过 CORS 的必然代价。如果 CORS 问题已经解决了，把它关掉。

也检查一下「响应流式模式」是不是被设成了非流式。

### 推理模型老是超时

去 **模型 → 默认模型策略与提示词 → 主请求超时**，默认 60 秒对重度思考模型偏短，调大它。

旁边的「启用自动恢复」保持开着，它会在流式失败时自动改用非流式重试一次。

### 某个模型删不掉，点了没反应

它正被设为「默认聊天模型」或「对话命名模型」。界面不会提前禁用按钮，你点了才会弹提示。先去把默认模型换成别的，再回来删。

### 用 Claude 订阅能跑普通对话吗

能。在提供商里添加 **Claude OAuth**，登录后照常给它加模型，在对话里正常选用。它底层走 Claude Agent SDK 而不是 HTTP 端点，所以「网络请求方式」这类传输层选项对它不适用。

这和 [CLI Agent](./cli-agent.md) 里的 Claude Code 是两回事——那个是驱动你本机的 CLI 进程。

## 对话

### 它为什么不知道我在看哪篇笔记

对话默认不读你当前打开的文件。用 `@` 引用，菜单第一项通常就是「当前文件」。

也可以在 Agent 编辑器里打开「**焦点同步**」，让它感知你正在看的位置。

### 它能读我的笔记，但改不了

你可能在 **Ask** 模式。Ask 不能编辑笔记正文，切到 **Agent**。

注意 Ask 也不是完全只读——它能执行 `mkdir`、`mv`、`rm` 这类文件整理操作，只是不改笔记里的字。

### 找不到 Max 模式

Max **仅桌面端**。移动端上模式会自动退回 Agent。

### 上下文占用只显示 token 数，没有百分比

那个模型没有配置上下文窗口 token。去模型设置里补上，百分比才算得出来。

### 撤销失败了

撤销依赖**本机快照**，而快照不随笔记同步。三种情况会失败：

- 你在另一台设备上想撤销这边的改动
- 文件在这期间被改过
- 快照已经过期丢失

真正重要的内容请依赖 Git 或 Obsidian 自己的文件恢复。

### 生成中还能发消息吗

能，会排队。但两种情况会被拦：有工具正等你审批时要先处理，模型正在问你问题时要先回答。

中止对话时还没发出的排队消息会退回输入框，不会丢。

## 灵光写作

### Tab 补全完全没反应

**Tab 补全默认是关闭的。** 去 **设置 → YOLO → 灵光写作 → 启用 Tab 补全** 打开它。

打开之后如果还是不触发，检查两件事：一是触发器表格里的规则有没有命中你的输入习惯（默认只在逗号、冒号、换行、列表项后触发），二是可以打开「自动补全（停顿后）」让它在你停止打字后也触发。

### Quick Ask 的 `@` 打不出来

Quick Ask 只在**空行行首**输入触发字符才会唤起。在有内容的行中间打 `@` 是正常的字符输入。

如果你就是经常需要在行首打 `@`，可以在设置里改触发字符。

## 知识库

### 索引时报 429 / 限流错误

把**嵌入并发数**调低。它默认是 10，对免费档或按分钟限额的服务（比如 Azure S0）太高了，调到 2–3 通常就正常。

### 改了分块大小，检索结果没变化

分块大小改完**只影响之后新索引的内容**。已有向量不会自动重算。

去命令面板跑一次「**重建整个库索引**」。

换嵌入模型同理，也必须重建。

### 选了嵌入模型但没生效

选中下拉之后**还要点一次「设为当前」**。

这一步不是多余的：切换嵌入模型会让所有已有向量失效，等于全库重建。多这一次点击是防止你手滑触发一次全量重建。

### 本地嵌入模型在哪下载 / 能删吗

在知识库标签页的嵌入模型区域，「本地（设备端）」货架。**仅桌面端**。

模型文件存在插件自己的目录里，不在你的库内、不参与同步。删除在模型条目上点两次确认。

## 工具和权限

### 工作区范围能不能当安全隔离用

**不能。** 如果这个 Agent 启用了终端命令或第三方 MCP 工具，范围可以被绕过——终端执行的是真实 shell，MCP 跑在外部进程里，都不经过 YOLO 的路径检查。

把它理解为"让 AI 专注在相关目录"的自主性约束，不是"把 AI 关进笼子"。

需要真隔离的话，做法是不给这个 Agent 终端和不受信的 MCP，而不是依赖范围设置。

### 它联网搜索之前怎么不问我

**联网搜索默认是"完全放行"的**，不会弹窗。介意的话去「管理工具」把它的审批档位调高，或者直接关掉。

### 开了自动放行，它会不会 `rm -rf` 我的东西

危险命令前缀黑名单**在任何情况下都生效**，包括自动放行模式。默认拦截 `rm`、`dd`、`mkfs`、`fdisk`、`shutdown`、`reboot`、`poweroff`、`halt` 开头的命令。

但这只是最后一道防线，不能替代备份。开自动放行之前请确认你的库在 Git 里。

### MCP 在手机上用不了

**MCP 仅桌面端**，不只是本地进程类型，远程的 HTTP / SSE / WebSocket 在移动端也一并禁用。

### 外部 Agent 接入提示端口冲突

默认端口 28124 被占了，最常见是和 Local REST API 之类的插件撞了。改一个端口即可。

## 数据和迁移

### YOLO 在我库里建的文件夹能改名吗

能。**设置 → YOLO → 其他 → 维护 → YOLO 根目录**，默认是 `YOLO`。

注意这是个**移动操作**：改了之后插件会尝试把旧目录的内容搬到新路径。如果目标路径已存在且非空，会拒绝并保留原设置。改之前先备份。

另外不能用隐藏文件夹（不能以 `.` 开头），否则 Obsidian 索引不到。

### 换电脑怎么把配置带过去

**设置 → YOLO → 其他 → 维护 → 导出配置**，导出成 JSON，在新设备上导入。

注意有些东西是**设备本地的，不会跟着走**：CLI 可执行文件路径、CLI 会话历史、本地嵌入模型文件、运行组件。

### 清空快照会丢对话吗

不会。「清空聊天快照与缓存」删的是上下文快照、编辑快照和时间线高度缓存，**聊天消息本身不受影响**。

清空之后首次打开旧对话会慢一些（要重建上下文和布局），这是正常的，不是数据损坏。

真正删对话的是「清空聊天记录」。

## 还是没解决

开一个 issue：

- 🐛 [报告 bug](https://github.com/Lapis0x0/obsidian-yolo/issues/new?template=bug_report_zh.yml)
- ✨ [提出想法](https://github.com/Lapis0x0/obsidian-yolo/issues/new?template=feature_request_zh.yml)

带上 Obsidian 版本、操作系统、插件版本、复现步骤和实际现象最有帮助。

如果问题出在模型请求上，可以打开 **设置 → YOLO → 其他 → 维护 → 启用 LLM 请求调试**，复现一次后从消息的 Debug 按钮导出原始请求。导出内容会脱敏 API 密钥，**但包含对话原文**，贴出来之前自己检查一遍。
