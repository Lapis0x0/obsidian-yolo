# 设置参考

按界面顺序速查每一项设置是干什么的。想了解某个功能怎么用，跟着链接去对应的功能篇。

设置页有六个标签：**模型 / Agent / 灵光写作 / 知识库 / 模块 / 其他**。

---

## 模型

详见[模型与提供商](./models.md)。

### 提供商

提供商卡片列表，可拖拽排序，点头部展开看它下面的模型。

**提供商编辑弹窗**的字段：

| 字段 | 说明 |
|------|------|
| ID | 仅供本地区分，不是 API 侧字段 |
| API 密钥 | 部分本地提供商不需要，可留空 |
| 基础 URL | 第三方或自建端点，有「预览」可看拼接后的完整地址 |
| 无 Stainless 请求头 | 解决 `x-stainless-*` 引起的 CORS 报错 |
| 使用 Obsidian requestUrl | 绕过 CORS，代价是失去流式响应 |
| 网络请求方式 | 自动 / 浏览器请求 / Obsidian 内置请求 / 桌面直连 |
| 响应流式模式 | 自动 / 流式 / 非流式 |
| 提示缓存 | 仅 Anthropic 系，默认开。写缓存有溢价，命中读取大幅便宜 |
| 自定义请求头 | 键值对，可多行 |

> 删除提供商会**级联删除**它下面的全部聊天模型、嵌入模型，并清空相关向量数据。

**聊天模型**每行可编辑，表头有「连通性测试」。正在被设为默认聊天模型或对话命名模型的模型无法删除或禁用。

**模型编辑**字段：调用 ID、展示名称、模型类型（推理档位）、输入模态、Provider 内置工具、上下文窗口 token、最大输出 token、请求参数、自定义参数。

### 默认模型策略与提示词

| 设置 | 默认 | 说明 |
|------|------|------|
| 默认聊天模型 | — | 所有对话界面默认用的 |
| 对话命名模型 | — | 自动生成对话标题用，适合配便宜的小模型 |
| 启用自动恢复 | 开 | 流式请求失败时自动改用非流式重试一次 |
| 主请求超时 | 60 秒 | 重度思考模型容易撞上，可调大 |
| 全局系统提示词 | 空 | 每次对话都会加在最前面。**支持 `![[笔记名]]` 嵌入笔记全文** |
| 对话标题提示词 | 空 | 留空用内置默认 |

## Agent

详见[工具与权限](./tools-and-permissions.md)和 [Agent 与子 Agent](./assistants.md)。

### 全局能力

两张卡片：**工具**和**技能**，各有一个「管理」按钮。

「管理工具」弹窗按三类列出全部内置能力——**库内操作 / 上下文与记忆 / 外部能力**。这里的开关是全局闸门，关掉后所有 Agent 都用不了。

部分能力有齿轮按钮进入专属设置：联网搜索（搜索服务商）、分析沙箱（子权限）、终端命令（危险前缀黑名单）、派遣子 Agent（模型池）。

弹窗底部是 **MCP 服务器管理**，**移动端整块隐藏**。

「管理技能」弹窗：初始化 Skills 系统、刷新、导入技能（拖拽或 GitHub 链接）、批量删除、逐个启用开关。

### Agents

Agent 卡片网格，可拖拽排序。内置的 **Default** 不能删除。

Agent 编辑器四个标签：

**资料** —— 名称、描述、图标、模型（可选「跟随默认模型」）、System prompt，以及三个开关：

| 开关 | 默认 | 说明 |
|------|------|------|
| 焦点同步 | 开 | 感知你当前在看哪篇笔记 / PDF 页 / 网页位置 |
| 当前时间感知 | 开 | 把发消息的时间注入给模型 |
| 读取项目指令文件 | 关 | 自动加载库根目录的 `AGENTS.md`、`CLAUDE.md` |

**工具** —— 启用工具、包含内置工具，以及逐个能力的启用状态和审批档位。MCP 服务器额外有披露模式（按需 / 常驻）和审批模式。顶部有 token 估算。

**技能** —— 逐个技能的启用和加载方式（全量注入 / 按需加载）。

**工作区** —— 「限制自主工作范围」开关加范围编辑器。**注意底部那行提示：启用了终端或第三方 MCP 时此范围可被绕过，不构成安全边界。**

### Agent 能力

四个折叠卡片，都是全局设置：

**图片读取**

| 设置 | 默认 | 说明 |
|------|------|------|
| 图片读取 | 开 | 关掉后下面三项隐藏 |
| 抓取外部图片链接 | **关** | 额外抓取 Markdown 里的图床/CDN 链接。单图超时 5 秒、超过 10MB 跳过。默认关是因为会向第三方发请求 |
| 图片压缩 | 开 | |
| 压缩质量 | 85 | **同时控制尺寸和画质**：填 60 表示尺寸缩到 60% 且画质 60%，不是两个独立参数 |

**上下文压缩**

| 设置 | 默认 | 说明 |
|------|------|------|
| 自动压缩上下文 | **关** | |
| 阈值模式 | — | 绝对 token 数 / 上下文窗口比例 |
| Prompt token 阈值 | 100000 | 选绝对模式时 |
| 窗口占用百分比 | 80% | 选比例模式时，需要模型已填上下文窗口值 |

> 触发后是**提醒 Agent 去压缩**，不是插件强制截断。

**外部 Agent 接入** —— 让外部 MCP 客户端反过来用你的库。**仅桌面端**，默认端口 28124。详见 [MCP](./mcp.md#把-yolo-提供给外部-agent)。

> Token 只在首次开启时生成，没有单独的重新生成按钮。需要换的话把开关关掉再打开。

**CLI 运行时** —— **仅桌面端**。为六个 CLI 分别指定可执行文件路径，留空自动检测。只存本设备，不随库同步。详见 [CLI Agent](./cli-agent.md)。

### 通知提醒

> 这块在界面上位于 **Agent 标签页的最底部**（虽然它的翻译键在 etc 命名空间下，在代码里搜索时容易找错地方）。

| 设置 | 默认 |
|------|------|
| 启用通知 | **关** |
| 通知方式 | 仅音效 |
| 提醒时机 | 仅失焦时提醒 |
| 需要审批时提醒 | 开 |
| 任务结束时提醒 | 开 |

## 灵光写作

详见[灵光写作](./sparkle.md)。

### 快捷指令

存在 `YOLO/snippets.md`，对话输入框打 `/` 触发。首次用点「初始化快捷指令」创建模板。

### Quick Ask

| 设置 | 默认 |
|------|------|
| 启用 Quick Ask | 开 |
| 自动停靠到右上角 | 开 |
| 触发字符 | `@`（限 1–3 字符） |
| 上文字符数 | 5000 |
| 下文字符数 | 2000 |

还有「续写预设」配置入口，管理续写档的快捷选项（名称、提示词、分类、图标，可拖拽排序）。快捷选项只能删除，没有"隐藏但保留"的开关。

### Cursor Chat

选中文字后浮出的工具条。可自定义快捷指令，每条配执行方式：Quick Ask 问答 / Quick Ask 改写 / 添加到对话框 / 添加到对话框并发送。

**每条自定义指令会自动注册成一条 Obsidian 命令**（前缀 `[Cursor Chat]`），可以单独绑快捷键。

### Tab 补全

| 设置 | 默认 | 说明 |
|------|------|------|
| 启用 Tab 补全 | **关** | 这是"灵光写作没反应"的最常见原因 |
| 补全模型 | 跟随续写模型 | 适合配小而快的模型 |
| 请求超时 | — | 1–120 秒 |
| 补全约束 | 空 | 附加要求，比如"使用中文" |
| 触发器表格 | 内置 6 条 | 中英文逗号、冒号、换行、列表项 |
| 触发延迟 | 3000ms | 最小 200ms |
| 自动补全（停顿后） | **关** | |
| 停顿时间 | 3000ms | |
| 冷却时间 | 15000ms | |

> 补全长度这类更细的调节在**编辑器内的灵光面板**里，不在这个设置页。

## 知识库

详见[知识库与检索](./knowledge-base.md)。

**顶部状态条**随状态变化：未开启时显示「开启并建立索引」按钮；正常时显示已索引篇数、待更新数量、自动更新开关、立即更新按钮，以及「…」菜单（重建全部索引 / 管理索引数据 / 关闭索引）。

**知识库卡片**每个可配四项：名称、描述（会提供给模型判断该查哪个库）、包含范围、排除范围。

**嵌入模型**分 API 模型和本地货架两块。

> 选中 API 模型后**还要点「设为当前」才生效**。多这一步是因为换嵌入模型等于全量重建索引。

本地嵌入**仅桌面端**，支持 CPU / GPU 切换。

**高级设置**（全局，不分知识库）：

| 设置 | 默认 | 说明 |
|------|------|------|
| 索引 PDF | 开 | 大库里关掉能提速 |
| 分块大小 | 1000 | **改完需要手动重建索引才生效** |
| 最小相似度 | 0.0 | |
| 限制 | 10 | 每次检索返回几条 |
| 嵌入并发数 | 10 | 1–24。**遇到 429 限流就调低** |

## 模块

左侧导航是「管理模块」「运行组件」，再往下是各个已启用模块自己的设置。

**运行组件**四个：分词器、PDF 引擎、Bash 引擎、嵌入引擎（仅桌面端）。

> 运行组件的开关管的是**组件存不存在**，「管理工具」里的开关管的是**工具对 AI 可不可见**。两者名字相近但不是一回事。

详见[模块](./modules.md)和[工具与权限](./tools-and-permissions.md#运行时组件)。

## 其他

### 支持 YOLO

Star、爱发电、Buy Me a Coffee，以及报 Bug 和提需求的链接（会自动带上版本号和系统信息）。

### 交互

| 设置 | 默认 | 说明 |
|------|------|------|
| 侧边栏图标点击位置 | 右侧边栏 | 可选新标签页 / 右侧分屏 / 独立窗口（仅桌面端）/ 上次的位置 |
| 使用 Enter 键换行 | 关 | 默认 Enter 发送。开启后改为 Cmd/Ctrl+Enter 发送 |
| 引用内容显示位置 | 输入框内 | 或顶部徽章 |
| `@` 文件上下文注入模式 | **轻量模式** | 轻量只注入路径、属性和结构，鼓励 AI 按需读取。**这项直接影响 token 消耗** |
| Chat 应用修改方式 | 先审阅后应用 | 改成「直接写入文件」后点应用不再二次确认，属于风险开关 |
| 保留选区块高亮 | 开 | |
| 聊天界面缩放 | 100% | 70%–150% |

### 聊天记录导出

| 设置 | 默认 |
|------|------|
| 导出思考过程 | 关 |
| 导出工具调用 | 关 |

### 维护

| 设置 | 默认 | 说明 |
|------|------|------|
| 更新提醒 | 开 | 关掉后本体和模块都不再提示新版本 |
| 自动下载更新 | 开 | 仅桌面端且插件目录可写时有效 |
| 导出 / 导入配置 | — | 换库迁移用 |
| **YOLO 根目录** | `YOLO` | 库内相对路径。改动是**移动操作**，见下 |
| 启用 LLM 请求调试 | 关 | 开启后每条消息多出 Debug 按钮，可查看原始请求响应 |

**YOLO 根目录**要注意：不能以 `/` 开头，不能是隐藏文件夹（`.` 开头会被拒绝）。改它会尝试把旧目录下的内容搬到新路径，**如果目标已存在且非空会拒绝并保留原设置**。这是高风险操作，改之前先备份。

**LLM 请求调试**的内容只存在当前会话内存里，重启 Obsidian 即清空。导出时会脱敏 API 密钥，**但仍然包含对话原文**——分享前自己检查一遍。

### 危险操作

都需要二次确认：

| 操作 | 影响 |
|------|------|
| 清空聊天记录 | 删除所有会话和消息 |
| 清空聊天快照与缓存 | 删上下文快照、编辑快照、时间线高度缓存，**不删消息本身**。清空后首次打开旧对话会变慢，不是数据丢失 |
| 重置供应商与模型 | 恢复默认配置，**覆盖而非合并** |
| 重置 Agent | 删除全部自定义 Agent，只留 Default |
| 重置设置 | 全部设置恢复出厂，放在整页最后一项 |
