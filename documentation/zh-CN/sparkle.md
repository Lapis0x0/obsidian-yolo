# 灵光写作

灵光写作（Sparkle）是一组**不用离开编辑器**的 AI 功能：光标处补全、改写选中的段落、唤起一个浮层提问。

它和[对话](./chat.md)走的是完全不同的路径——单轮生成、低延迟、不经过工具调用和审批。这意味着它快，但也意味着它不会读你的其他笔记、不会改别的文件。

配置位置：**设置 → YOLO → 灵光写作**。

## Quick Ask 浮层

在编辑器里随手问一句、随手改一段，结果直接落到光标处。

### 唤起

两种方式：

- **在空行行首输入 `@`** —— 触发字符可以在设置里改（限 1–3 个字符）。输入后该字符会被自动清除，浮层在光标附近弹出
- **命令面板 → 触发 Quick Ask**

浮层默认会在你发送问题后**自动停靠到编辑器右上角**，不挡住正文；你手动拖动过一次之后，它就不再自动跟随了。

### 三档模式

浮层里用 Tab 切换，不是三个独立入口：

| 档位 | 做什么 |
|------|--------|
| **Ask** | 问答，只读权限，和侧栏对话的 Ask 模式一致 |
| **Agent** | 同一个浮层里跑 Agent，可以读写笔记、执行多步骤任务 |
| **续写** | 不走 Agent 和工具链，在光标处直接续写 |

**续写档可以什么都不输入直接发送**——它会顺着当前上下文往下写。也可以给一句具体要求控制方向，比如"接着写三条反例"。

### 结果怎么用

浮层里有这些操作：**复制**、**插入**（到光标位置）、**在侧边栏打开**（把这段对话转到侧栏继续，适合聊着聊着发现要深入）、停止、清空对话。

### 上下文范围

Quick Ask 会带上光标前后的正文，默认上文 5000 字符、下文 2000 字符，都可以在设置里调。

### 续写预设

续写档可以配快捷选项，省得每次手打指令。在设置里点「配置快捷选项」，每个选项可以设名称、提示词、分类（建议 / 撰写 / 思考 / 自定义）和图标，支持拖拽排序。

内置九个预设，改乱了可以「恢复默认」。

> 快捷选项只能删除，没有"隐藏但保留"的开关。

## Tab 补全

打字时在光标处给出灰色的补全建议，按 Tab 接受。

> **Tab 补全默认是关闭的。** 这是最常见的"灵光写作怎么没反应"的原因。去设置里打开它。

### 什么时候会触发

两种触发方式，可以同时开：

**模式触发**（默认）—— 光标前的文字命中规则时弹出建议。内置六条规则：中英文逗号、中英文冒号、换行、列表项开头（`- ` `* ` `+ `）。你可以在触发器表格里逐条开关、增删、改成正则匹配。

**空闲触发**（默认关闭）—— 停止打字一段时间后自动触发，默认 3 秒。带 15 秒冷却，防止一直打断你。

也可以用命令面板的「触发 Tab 补全」手动来一次。

### 接受和拒绝

| 按键 | 作用 |
|------|------|
| `Tab` | 接受建议 |
| `↑` / `↓` | 在多个候选之间切换 |
| `Shift+Tab` / `Esc` / `Backspace` | 拒绝并清除建议 |

命令面板里还有一个「接受补全」命令，方便你绑定到别的按键，或者给 Commander 这类插件调用。

### 可调的参数

- **补全模型** —— 可以和默认聊天模型分开。这里适合用小而快的模型，延迟比聪明更重要。**留空的话会回退到续写模型**
- **请求超时** —— 1 到 120 秒
- **补全约束** —— 一段附加要求，比如"使用中文"、"不要补全代码块"
- **触发延迟** —— 最小 200 毫秒

> 设置页里只有这些基础参数。补全长度这类更细的调节在编辑器内的灵光面板里，不在插件设置页。

## 选区改写

选中一段文字后会浮出一个工具条（不是系统右键菜单），上面有这些动作：

| 动作 | 说明 |
|------|------|
| **添加到对话** | 把选区作为引用加进当前对话输入框 |
| **添加到侧边栏** | 发送到侧栏对话，侧栏没开会自动打开 |
| **自定义改写** | 输入改写指令，只改这段选区 |
| **自定义提问** | 针对这段内容提问 |
| **深入解释** / **提供建议** / **翻译成中文** | 内置预设动作 |
| **调整篇幅** | 拖动手柄精简或扩写（暂不支持表格选区） |

自定义改写的输入框里，**Shift+回车 确认**，回车是换行，Esc 关闭。

改写**只影响选区内的内容**，不会像 Agent 那样动到全文或别的文件。如果你在等结果的时候又编辑了原文导致选区失效，它会提示你重新选择。

### 自定义快捷指令

设置里的「Cursor Chat」区块可以增删这些快捷动作。每条可以配：标签、指令文本、执行方式、绑定的 Agent。

执行方式有四种：

- **Quick Ask 问答** —— 自动发送
- **Quick Ask 改写** —— 进入预览，可以再选"弹出输入框"还是"直接用预置指令生成"
- **添加到对话框** —— 只填进去，不发送
- **添加到对话框并发送**

每条自定义指令会**自动注册成一条 Obsidian 命令**（前缀 `[Cursor Chat]`），所以你可以在快捷键设置里单独给它绑按键。

## 相似笔记

侧栏的灵光写作标签页里有个「相似笔记」面板，基于你当前打开的笔记做向量检索，列出相关的其他笔记，可以展开看命中的片段，或者在光标处插入链接。

它依赖[知识库](./knowledge-base.md)——需要配好嵌入模型，并且当前这篇笔记已经被索引过。没配好时面板会给出对应的引导按钮。

## 全局的 Esc

任何时候按 **Esc** 都会取消所有正在进行的 AI 续写和改写任务。这个是全局生效的，不影响 Esc 本来的其他行为（比如关闭弹窗）。
